# Изменения

Формат по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено
- Вкладки экземпляра — таблетки M3 Expressive: выбранную подсвечивает пилюля, которая переезжает на пружине. Новая вкладка «Шейдеры».
- Моды, ресурспаки и шейдеры экземпляра на одном экране: слева установленное, справа каталог Modrinth или CurseForge этого же типа под версию экземпляра, между ними перетаскиваемый разделитель. В узком окне половины переключаются кнопками. Поиск в каталоге справа переживает страницу мода.
- Нагрузка модов: во время игры встроенный профилировщик Java (JFR) отмечает, какой код работает и где выделяется память; на вкладке «Обзор» рейтинг модов по процессору и памяти, средняя загрузка процессора, пик памяти и паузы сборщика мусора по последним пяти сессиям. Данные только на этом компьютере; нужна Java 11+, выделение памяти по модам — Java 16+; выключается в настройках экземпляра.
- Ползунок прокрутки в духе Material You в выборе версии игры и загрузчика: расширяется на пружине, при перетаскивании показывает номер версии в пузыре, нажатие на дорожку плавно прокручивает к месту.

### Исправлено
- Каталог модов сбрасывался на Modrinth и терял поиск, если его открыли из экземпляра, а со страницы мода вернулись через меню «Моды».
- Кнопки на пустых экранах (например, «Перейти в Modrinth» без ключа CurseForge) сжимались в столбик в узком окне: теперь переносятся на новую строку.

## [1.2.0] — 2026-10-25

### Добавлено
- Установщик `YouLauncher-<версия>-Setup.exe` в Material 3 Expressive: живой фон из фигур и шестерёнок, рассказ о возможностях, выбор диска и папки с проверкой места, ярлыки, запись в «Приложения» Windows. Ставится для текущего пользователя без прав администратора, обновляет прежнюю установку; удаление из «Приложений» оставляет данные, если не попросить иначе.
- Кэш классов Java: список классов готовится при сборке, архив собирается в фоне на компьютере пользователя; классы экранов заранее подгружаются в фоне.
- Вход через Microsoft по коду устройства: Xbox Live, XSTS, вход в Minecraft, проверка покупки игры, скин в аватаре; сессия обновляется сама и хранится в диспетчере учётных данных Windows. Кнопка появляется в сборке с ID приложения Azure, одобренного Mojang.

### Улучшено
- Отзывчивость: первое открытие библиотеки 1,2 с → 0,27 с, настроек экземпляра 0,64 с → 0,05 с, остальные экраны быстрее 0,15 с, повторные переходы быстрее 0,08 с. Общий кэш цветовых схем, ленивый список в настройках экземпляра, без полных сборок мусора в первые минуты.
- Встроенная Java урезана до нужных модулей: программа меньше на 46 МБ.

### Исправлено
- Превью живых обоев в настройках были сильно размыты.
- В каталоге модов после просмотра страницы мода сбрасывались поиск, фильтры, отмеченные моды и прокрутка.
- В поиске каталога модов, списке модов экземпляра, выборе версии и палитре команд не было кнопки очистки.
- Настройки прыгали в начало после первого своего цвета или смены языка.
- Заставка показывалась повторно при смене языка.

## [1.1.0] — 2026-10-24

### Добавлено
- Голова скина Ely.by в аватаре профиля, в заголовке окна и в списке аккаунтов; скин обновляется при открытии панели профиля.
- Вариант фона «Своё изображение» в настройках фона.
- Оформление отдельного экземпляра из его шапки: свой баннер и свой фон, которые видны только в этом экземпляре.
- Аргументы запуска `--open <экран>` и `--launch <id>`.

### Исправлено
- Скины Ely.by не загружались из-за ссылок по http.
- Ярлык экземпляра на рабочем столе не запускал игру.

### Улучшено
- Потребление памяти снижено примерно с 410 до 250–300 МБ: шрифт загружается один раз, лёгкий сборщик мусора, кэш картинок ограничен по размеру, память освобождается при сворачивании окна.

## [1.0.0] — 2026-10-24

Первый выпуск.

### Игра
- Установка и запуск любой версии Minecraft Java Edition с официальных серверов Mojang, проверка SHA-1, докачка, работа без сети для установленных версий.
- Загрузчики Fabric, Quilt, Forge и NeoForge, обновление загрузчика.
- Смена версии игры и загрузчика у готового экземпляра с проверкой совместимости модов.
- Починка экземпляра: полная проверка файлов версии, загрузчика и модов.
- Консоль игры, экран сбоя игры, запуск с заходом на сервер.

### Моды и сборки
- Каталоги Modrinth и CurseForge (моды, ресурспаки, шейдеры, сборки), встроенный ключ CurseForge или свой.
- Окно зависимостей перед установкой, пакетная установка выбранных модов с деревом зависимостей.
- Проверка и установка обновлений, наборы модов.
- Импорт `.mrpack`, CurseForge, MultiMC/Prism; экспорт в `.mrpack` и Prism.

### Аккаунты
- Офлайн-аккаунты и Ely.by (скины, двухфакторная защита, authlib-injector с проверкой хеша).
- Токены в Диспетчере учётных данных Windows.
- Выдвижная панель профиля из аватара в заголовке окна.

### Java
- Автоподбор Java под версию игры, загрузка с серверов Mojang или Eclipse Temurin, проверка установок.

### Экземпляры
- Серверы из `servers.dat`, пинг, значки.
- Цвет и обложка карточки, резервные копии вручную и по расписанию.

### Оформление
- Material 3 Expressive: пружинные анимации трёх уровней, морфинг форм, волнистые индикаторы.
- 28 встроенных обоев и живые фоны из кода, параллакс по глубине, свои изображения, цвета из обоев.
- Свой цвет для каждой из 35 ролей схемы M3.
- Эмблемы главной новинки версии в мастере создания.

### Система
- Палитра команд, горячие клавиши, режим окна, виджеты главной, перенос настроек.
- Уведомления Windows, звуки интерфейса, автоочистка кэша.
- Экран ошибки лаунчера с отчётом, отчёт для диагностики без секретов.
- Автообновление из GitHub Releases с проверкой sha256, каналы «Стабильные» и «Бета».
- Портативная сборка, установщики MSI и EXE, русский и английский языки.
