## 🌍 English

**Installer:** download **`YouLauncher-1.3.0-Setup.exe`** below. **Portable:** **`YouLauncher-1.3.0-windows.zip`**. On 1.2.1+ the launcher offers the update itself.

### Added
- ⚡ **Horizon as an instance type.** [Horizon](https://github.com/horizon-rust/horizon) (MIT) is Minecraft Java Edition 26.3 rewritten in Rust. Pick **Horizon** next to Fabric and NeoForge in the new-instance wizard; its versions are its GitHub releases. On the first launch the launcher downloads the release (SHA-256 checked), the Minecraft 26.3 files from Mojang, Java 25, prepares Horizon's resources once per version (a couple of minutes) and starts the game. Worlds and settings stay in the instance folder. Microsoft accounts are handed over in a session file, offline accounts by name. Needs a GPU with Vulkan.
- 🧩 **Horizon's mod store.** The Mods tab of a Horizon instance opens Horizon's reviewed registry: Zoom, FPS Counter, Minimap, Keystrokes, Coordinates HUD, Mod Menu and more. Install, update, turn on and off, remove; every file is checked by size and SHA-256, signed projects by their author's signature, and mods taken down from the registry are turned off before launch. Java mods don't run in Horizon.

### Fixed
- ⌨️ **Text fields.** Instance settings lost keystrokes when typing fast, Tags didn't accept a comma, an unfinished environment variable line was erased, Width and Height couldn't be cleared. Library search could lose keystrokes, HEX color fields moved the caret, Esc now ends editing in the profile.

## 🌏 Русский

**Установщик:** скачайте **`YouLauncher-1.3.0-Setup.exe`** ниже. **Портативная версия:** **`YouLauncher-1.3.0-windows.zip`**. В 1.2.1 и новее лаунчер сам предложит обновление.

### Добавлено
- ⚡ **Horizon — отдельный вид экземпляра.** [Horizon](https://github.com/horizon-rust/horizon) (MIT) — Minecraft Java Edition 26.3, переписанный на Rust. Выберите **Horizon** рядом с Fabric и NeoForge в мастере создания; его версии — релизы на GitHub. При первом запуске лаунчер скачивает релиз (проверка SHA-256), файлы Minecraft 26.3 с серверов Mojang, Java 25, один раз на версию готовит ресурсы Horizon (пара минут) и запускает игру. Миры и настройки — в папке экземпляра. Аккаунт Microsoft передаётся файлом сессии, офлайн — ником. Нужна видеокарта с Vulkan.
- 🧩 **Магазин модов Horizon.** Вкладка «Моды» у экземпляра Horizon открывает его проверяемый реестр: Zoom, FPS Counter, Minimap, Keystrokes, Coordinates HUD, Mod Menu и другие. Установка, обновление, включение, удаление; каждый файл сверяется по размеру и SHA-256, подписанные — по подписи автора, снятые с реестра моды выключаются перед запуском. Java-моды в Horizon не работают.

### Исправлено
- ⌨️ **Поля ввода.** В настройках экземпляра терялись символы при быстром наборе, в «Тегах» не ставилась запятая, в «Переменных окружения» стиралась недописанная строка, «Ширину» и «Высоту» нельзя было очистить. Поиск в библиотеке мог терять символы, поле HEX сдвигало курсор, в профиле Esc теперь завершает правку.

> Horizon — молодой проект: FPS пока ниже, чем у обычного Minecraft. Если упирается в частоту монитора, выключите VSync в настройках графики Horizon. Новые версии Horizon выходят часто — обновить можно в экземпляре.
