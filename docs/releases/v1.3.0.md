## 🌍 English

### ⚡ Horizon: Minecraft in Rust, as an instance
[Horizon](https://github.com/horizon-rust/horizon) (MIT) is Minecraft: Java Edition 26.3 rewritten in Rust. Pick **Horizon** next to Fabric and NeoForge in the new-instance wizard: the launcher downloads the release (SHA-256 checked), the Minecraft 26.3 files from Mojang and Java 25, prepares Horizon's resources once per version and starts the game. Worlds and settings stay in the instance folder; Microsoft accounts are handed over in a session file, offline ones by name. Needs a GPU with Vulkan.

### 🧩 Horizon's mod store
The **Mods** tab of a Horizon instance opens Horizon's reviewed registry — Zoom, FPS Counter, Minimap, Keystrokes, Coordinates HUD, Mod Menu and more — with what each mod may do written out. Install, update, turn on and off, remove. Every file is checked by size and SHA-256, signed projects by their author's signature, and mods taken down from the registry are turned off before launch.

<img src="https://raw.githubusercontent.com/nurudinsaidov98-commits/YouLauncher/main/docs/screens/en/horizon-mods-dark.png" width="100%" alt="Horizon's mod store">

### ⌨️ Text fields, fixed everywhere
Instance settings no longer lose keystrokes when you type fast; **Tags** accept a comma, an unfinished **environment variable** line stays, **Width** and **Height** can be cleared. Library search keeps every keystroke, HEX color fields keep the caret, and **Esc** ends editing in the profile.

> Horizon is a young project by its own authors: Java mods don't run in it and FPS is still lower than in regular Minecraft. If it is capped at your monitor's refresh rate, turn VSync off in Horizon's video settings. New Horizon versions come often — update them right in the instance.

### ⚡ Horizon: Minecraft на Rust отдельным экземпляром
[Horizon](https://github.com/horizon-rust/horizon) (MIT) — Minecraft: Java Edition 26.3, переписанный на Rust. Выберите **Horizon** рядом с Fabric и NeoForge в мастере создания: лаунчер скачает релиз (проверка SHA-256), файлы Minecraft 26.3 с серверов Mojang и Java 25, один раз на версию подготовит ресурсы Horizon и запустит игру. Миры и настройки — в папке экземпляра; аккаунт Microsoft передаётся файлом сессии, офлайн — ником. Нужна видеокарта с Vulkan.

### 🧩 Магазин модов Horizon
Вкладка **«Моды»** у экземпляра Horizon открывает его проверяемый реестр — Zoom, FPS Counter, Minimap, Keystrokes, Coordinates HUD, Mod Menu и другие, — и у каждого мода видно, что ему разрешено. Установка, обновление, включение, удаление. Каждый файл сверяется по размеру и SHA-256, подписанные — по подписи автора, а снятые с реестра моды выключаются перед запуском.

<img src="https://raw.githubusercontent.com/nurudinsaidov98-commits/YouLauncher/main/docs/screens/horizon-mods-dark.png" width="100%" alt="Магазин модов Horizon">

### ⌨️ Поля ввода исправлены везде
В настройках экземпляра больше не теряются символы при быстром наборе; в **«Тегах»** ставится запятая, недописанная строка **переменных окружения** не стирается, **«Ширину»** и **«Высоту»** можно очистить. Поиск в библиотеке не теряет символы, поле HEX не сдвигает курсор, **Esc** завершает правку в профиле.

> Horizon — молодой проект своих авторов: Java-моды в нём не работают, а FPS пока ниже, чем в обычном Minecraft. Если FPS упирается в частоту монитора, выключите VSync в настройках графики Horizon. Новые версии Horizon выходят часто — обновить можно прямо в экземпляре.
