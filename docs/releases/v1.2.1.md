## 🌍 English

### Install

| 💿 Installer — recommended | 📦 Portable |
|---|---|
| Download **`YouLauncher-1.2.1-Setup.exe`** below and run it. Already on 1.2.0? It updates in place, your instances stay. | Download **`YouLauncher-1.2.1-windows.zip`**, unzip anywhere and run **`YouLauncher-App\YouLauncher.exe`**. |

On 1.2.0 the launcher offers this update by itself: **Settings → About → Update and restart**.

### What's new
- 💊 **Pill tabs** — instance tabs live in an M3 Expressive pill, the selected one is highlighted by a pill that slides on a spring. New **Shaders** tab.
- 🧩 **Installed | Catalog side by side** — mods, resource packs and shaders: what you have on the left, the Modrinth or CurseForge catalog of the same type, filtered for the instance, on the right. Drag the divider to resize.
- 🖱️ **Drag and drop** — drag an installed mod onto the catalog to remove it, drag a catalog project onto the installed list to install it.
- ↕️ **Sorters at the divider** — installed: name, newest, largest, enabled or updates first; catalog: relevance, downloads, follows, newest, updated.
- ↩️ **Undo removal** — removed files can be brought back from the snackbar; after ten minutes they go to the Windows Recycle Bin.
- 📊 **Mod load** — while you play, the built-in Java profiler (JFR) notes which code runs and where memory is allocated. The Overview tab ranks mods by CPU and memory and shows average CPU, peak memory and GC pauses. Local only; Java 11+ (Minecraft 1.17+), per-mod memory on Java 16+; can be turned off per instance.
- 🎚️ **Material You scrollbar** in the version picker: springy thumb with a version bubble while dragging.
- 🐞 The mods catalog no longer resets to Modrinth after opening it from an instance; empty-state buttons wrap in narrow windows.

## 🌏 Русский

### Установка

| 💿 Установщик — рекомендуем | 📦 Портативная версия |
|---|---|
| Скачайте **`YouLauncher-1.2.1-Setup.exe`** ниже и запустите. Уже стоит 1.2.0 — обновится поверх, экземпляры останутся. | Скачайте **`YouLauncher-1.2.1-windows.zip`**, распакуйте в любую папку и запустите **`YouLauncher-App\YouLauncher.exe`**. |

В 1.2.0 лаунчер сам предложит это обновление: **Настройки → О программе → «Обновить и перезапустить»**.

### Что нового
- 💊 **Вкладки-таблетки** — вкладки экземпляра в таблетке M3 Expressive, выбранную подсвечивает пилюля на пружине. Новая вкладка **«Шейдеры»**.
- 🧩 **Установлено | Каталог рядом** — моды, ресурспаки и шейдеры: слева то, что стоит, справа каталог Modrinth или CurseForge того же типа под версию экземпляра. Разделитель можно тянуть.
- 🖱️ **Перетаскивание** — мод из установленного в каталог — удалить, из каталога в установленное — поставить.
- ↕️ **Сортировщики у разделителя** — установленное: по названию, новые, тяжёлые, включённые или с обновлениями сверху; каталог: по релевантности, загрузкам, подписчикам, новизне, обновлению.
- ↩️ **Отмена удаления** — удалённое возвращается кнопкой «Отменить»; через десять минут файл уходит в корзину Windows.
- 📊 **Нагрузка модов** — во время игры встроенный профилировщик Java (JFR) отмечает, какой код работает и где выделяется память. На вкладке «Обзор» рейтинг модов по процессору и памяти, средняя загрузка процессора, пик памяти и паузы сборщика. Только на этом компьютере; Java 11+ (Minecraft 1.17+), память по модам — Java 16+; выключается в настройках экземпляра.
- 🎚️ **Ползунок Material You** в выборе версии: пружинит и показывает номер версии в пузыре.
- 🐞 Каталог модов больше не сбрасывается на Modrinth после открытия из экземпляра; кнопки пустых экранов переносятся в узком окне.
