## 🌍 English

### Install
1. Download **`YouLauncher-1.1.0-windows.zip`** below.
2. Unzip it and run **`YouLauncher-App\YouLauncher.exe`** — Java is bundled.

### Highlights
- 🌀 **Material 3 Expressive everywhere** — spring animations (Standard, Bouncy, Jelly), shape-morphing buttons, wavy progress, M3 loading indicators.
- 🎨 **Dynamic color** from a seed, your wallpaper or the selected version, plus your own color for each of the 35 M3 color roles.
- 🌄 **Living backgrounds** — 28 built-in wallpapers and live backgrounds drawn by code, depth parallax, adjustable blur, your own images, and a separate background and banner for any instance.
- 🏷️ **Version emblems** — the key feature of each update drawn from M3 shapes in the version picker.
- 🎮 **Any Minecraft version** from official Mojang servers, **Fabric, Quilt, Forge, NeoForge**.
- 🧩 **Modrinth and CurseForge** — dependencies window, multi-select *Install all*, updates, mod sets, modpack import and export.
- 👤 **Offline and Ely.by accounts** with skin heads in the profile, two-factor sign-in, tokens in Windows Credential Manager.
- 🛡️ Instance repair, scheduled backups, servers with ping, Java auto-pick and Temurin downloads.
- ⚡ About **250–300 MB of RAM** with every animation on.
- 🔄 Auto-update from GitHub Releases with sha256 verification.

## 🌏 Русский

### Установка
1. Скачайте **`YouLauncher-1.1.0-windows.zip`** ниже.
2. Распакуйте и запустите **`YouLauncher-App\YouLauncher.exe`** — Java уже внутри.

### Главное
- 🌀 **Material 3 Expressive везде** — пружинные анимации (Стандарт, Упругие, Желе), кнопки с морфингом формы, волнистый прогресс, индикаторы загрузки M3.
- 🎨 **Динамический цвет** из одного цвета, ваших обоев или выбранной версии, плюс свой цвет для каждой из 35 ролей схемы M3.
- 🌄 **Живые фоны** — 28 встроенных обоев и живые фоны из кода, параллакс по глубине, настраиваемое размытие, свои картинки, отдельный фон и баннер для любого экземпляра.
- 🏷️ **Эмблемы версий** — главная новинка каждого обновления, нарисованная формами M3 в выборе версии.
- 🎮 **Любая версия Minecraft** с официальных серверов Mojang, **Fabric, Quilt, Forge, NeoForge**.
- 🧩 **Modrinth и CurseForge** — окно зависимостей, «Установить всё» для выбранных модов, обновления, наборы модов, импорт и экспорт сборок.
- 👤 **Офлайн-аккаунты и Ely.by** с головой скина в профиле, двухфакторной защитой и токенами в диспетчере учётных данных Windows.
- 🛡️ Починка экземпляра, резервные копии по расписанию, серверы с пингом, автоподбор Java и загрузка Temurin.
- ⚡ Около **250–300 МБ памяти** со всеми анимациями.
- 🔄 Автообновление из GitHub Releases с проверкой sha256.
