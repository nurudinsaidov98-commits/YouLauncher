## 🌍 English

### Install

| 💿 Installer — recommended | 📦 Portable |
|---|---|
| Download **`YouLauncher-1.2.0-Setup.exe`** below, run it, pick a drive and a folder. Shortcuts and an entry in Windows *Apps* included, no admin rights needed. | Download **`YouLauncher-1.2.0-windows.zip`**, unzip it anywhere and run **`YouLauncher-App\YouLauncher.exe`**. |

Already on 1.1.0? The launcher offers the update itself, or just run the installer: your instances, worlds and settings stay.

### What's new
- 💿 **Installer in Material 3 Expressive** — a living background of M3 shapes and spinning gears, morphing transitions, drive picker with a free-space check, shortcuts, uninstall from Windows *Apps* that keeps your data.
- ⚡ **Much snappier** — the library opens in 0.27 s instead of 1.2 s on first visit, instance settings in 0.05 s instead of 0.64 s; a Java class cache is built on your PC in the background.
- 🔍 **Mods catalog keeps its state** — search, filters, selected mods and scroll survive opening a mod page; every search field got a clear button.
- 🖼️ Live wallpaper previews are sharp again; settings no longer jump to the top after a change.
- 🪶 The bundled Java is trimmed to what the launcher needs: 46 MB smaller.
- 🟩 Microsoft sign-in is built in and will be switched on once Mojang approves the app.

## 🌏 Русский

### Установка

| 💿 Установщик — рекомендуем | 📦 Портативная версия |
|---|---|
| Скачайте **`YouLauncher-1.2.0-Setup.exe`** ниже, запустите и выберите диск и папку. Ярлыки и запись в «Приложениях» Windows в комплекте, права администратора не нужны. | Скачайте **`YouLauncher-1.2.0-windows.zip`**, распакуйте в любую папку и запустите **`YouLauncher-App\YouLauncher.exe`**. |

Уже стоит 1.1.0? Лаунчер сам предложит обновиться, или просто запустите установщик: экземпляры, миры и настройки останутся.

### Что нового
- 💿 **Установщик в Material 3 Expressive** — живой фон из фигур M3 и вращающихся шестерёнок, перетекающие переходы, выбор диска с проверкой места, ярлыки, удаление из «Приложений» Windows с сохранением данных.
- ⚡ **Заметно быстрее** — библиотека при первом открытии 0,27 с вместо 1,2 с, настройки экземпляра 0,05 с вместо 0,64 с; кэш классов Java собирается на вашем компьютере в фоне.
- 🔍 **Каталог модов помнит состояние** — поиск, фильтры, отмеченные моды и прокрутка сохраняются после страницы мода; во всех полях поиска появилась кнопка очистки.
- 🖼️ Превью живых обоев снова чёткие; настройки больше не прыгают в начало после изменения.
- 🪶 Встроенная Java урезана до нужного лаунчеру: на 46 МБ меньше.
- 🟩 Вход через Microsoft встроен и включится, когда Mojang одобрит приложение.
